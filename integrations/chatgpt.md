# Use memory in ChatGPT

Add a reviewed Markdown memory page to a ChatGPT conversation for a single task, or to a project when several conversations need the same source. The local vault remains the primary copy. [ChatGPT projects and sources](https://learn.chatgpt.com/docs/projects)

## Select and add memory

1. Open the vault and choose the individual notes needed for the task. `index.md` lists the available pages. Review the selected Markdown and its source references before sharing it.
2. For a single conversation, attach the selected notes. For recurring work, open the intended project and add them under **Sources**. Confirm the project's audience before adding work information.
3. Ask ChatGPT to use the notes as reference material. For example, “Use the attached decision notes. Cite the filename and any source tag for each claim. Flag older decisions when a newer one replaces them.”

The files reflect the version added to ChatGPT. To refresh a project source, review and add the current note. Keep private session transcripts, queues, and indexes on the machine. [Working with files in ChatGPT](https://learn.chatgpt.com/docs/use-chatgpt)

## Use the same vault in Codex

Codex runs the recall hook locally on prompt submission. Its adapter uses the current prompt and returns relevant excerpts as additional context. The [Codex setup](codex.md) covers the installer and hook verification. ChatGPT Work can also read files from a chosen local project folder when that workspace enables local work. [ChatGPT desktop app](https://learn.chatgpt.com/docs/app)
